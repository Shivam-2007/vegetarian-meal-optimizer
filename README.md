# vegetarian-meal-optimizer
Project Overview

Vegetarian Meal Optimizer is a Java application designed to help college students find affordable, filling, and nutritious vegetarian meals. It allows users to compare meals based on cost per serving, calories, protein content, and individual satiety ratings.

Problem

College students often struggle to find affordable vegetarian meals that provide sufficient protein and keep them satisfied without exceeding their food budgets. Comparing meal prices, nutritional information, and personal experiences can be time-consuming.

MVP Features

Browse a collection of vegetarian meals.

View estimated cost per serving.

View calories and protein per serving.

Submit individual satiety ratings on a scale of 1–10.

View average satiety ratings.

Filter and compare meals based on price, calories, and protein.

Future Plans

Expand the meal database.

Add weekly meal planning.

Include grocery price comparisons.

Add personalized meal recommendations.

Incorporate more detailed nutritional information.

Tech Stack

Language: Java

IDE: IntelliJ IDEA Community Edition

Libraries: Gson for JSON processing.

GUI: Java Swing.

Data Storage: JSON files.

Version Control: Git and GitHub.

Nutritional Data: USDA FoodData Central.
